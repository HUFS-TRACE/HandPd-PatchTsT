모든 CSV는 UTF-8(BOM) 형식이라 엑셀에서 더블클릭하면 한글이 깨지지 않고 열린다.
값은 `python paper/figure_data/extract_figure_data.py`로 `results/` 원자료에서 다시 뽑은 것이고, 원본 그림과 대조해 일치를 확인했다.
표 1~6은 본문 docx에 숫자가 그대로 있으므로 따로 추출하지 않았다.

## 그림 1. 연령 교란 통제 (좌우 2패널)

### (a) 꺾은선 그래프: `fig1a_정확도.csv`
- 가로축에는 R0 / R4 / R5 세 조건을 두고, 눈금 라벨 둘째 줄에 `전체 61명`, `2016년 제외 40명`, `45세 이상 41명`을 적는다.
- 세로축은 피험자 정확도이고 범위는 0.53~0.95, 눈금 간격은 0.05다.
- 선 3개:
  - PatchTST 모델: 남색 실선, 원 마커, 굵게. 점 위에 값(0.813 / 0.849 / 0.805)을 굵은 글씨로 단다.
  - 연령 규칙(임계 재최적화): 빨강 파선, 사각 마커. 값(0.738 / 0.775 / 0.659)은 점 아래에 단다.
  - 다수결 기준선: 회색 점선, 삼각 마커, 가늘게. 값 라벨은 달지 않는다.
- 그래프 위쪽(y≈0.92)에 회색 둥근 상자로 `연령차 +14.7세 / +11.3세 / +3.3세`를 넣는다.
- 범례는 그래프 아래에 3열로 둔다.
- 제목: (a) 연령을 맞추면 규칙은 무너지고 모델은 버틴다

### (b) 막대 그래프: `fig1b_모델-규칙.csv`
- 가로축 R0 / R4 / R5 아래 줄에 연령차를 적는다.
- 세로축은 "모델 정확도 - 연령 규칙"이고 범위는 0~0.20이다.
- 막대 색은 R0과 R4를 연회청, R5만 남색으로 한다.
- 막대 위에 `+0.075 / +0.074 / +0.146`을 굵게 적는다.
- 왼쪽 위에 "연령을 대리 학습했다면 / 반대 방향이어야 한다"라는 글을 넣고, R5 막대를 가리키는 곡선 화살표를 그린다.
- 제목: (b) 교란을 끊을수록 우위가 커진다

엑셀에서는 (a)를 "꺾은선형(표식 포함)", (b)를 "묶은 세로 막대형"으로 만든다. 막대 하나만 색을 바꾸려면 그 막대만 클릭해서 채우기를 바꾸면 된다.

## 그림 2. 난이도 분산과 연산량 (좌우 2패널)

### (a) 누적 히스토그램: `fig2a_히스토그램_구간.csv`
- 0~0.5를 **14개 같은 폭 구간(폭 0.0357)** 으로 나눠 이미 개수를 세어 두었다.
- 누적 세로 막대로 그린다. 아래는 환자 수(남색), 위는 정상 수(회청)이고, 막대 사이 간격은 0으로, 테두리는 흰색으로 한다.
- x=0.1에 빨간 세로 파선을 긋고, 0~0.1 구역은 연한 빨강으로 칠한다.
- 파선 오른쪽 위에 빨간 글씨로 "애매한 피험자 11명 / (시드별 10~13명 · 16~21%)"를 넣는다.
- x축은 "판정 명확도 |p - 0.5| (시드 3개 평균)", y축은 "피험자 수"(0~9)다.
- 범례는 환자 (n=26), 정상 (n=35)이다.
- 제목: (a) 난이도 분산은 실재한다
- 참고로 `fig2a_피험자별_명확도.csv`는 61명 각각의 원값이다. 히스토그램을 직접 세고 싶을 때 쓰면 되고, 명확도 순으로 정렬돼 있다. 피험자 ID는 번호로 바꿨다.

엑셀 팁: x축 라벨은 구간 시작값을 쓰되 0.0, 0.1, … 만 보이게 해도 된다. 막대 간격 0%는 "데이터 계열 서식 → 간격 너비 0%"에서 설정한다.

### (b) 산점도 + 오차막대: `fig2b_연산량_AUC.csv`
- x축은 MFLOPs이고 **로그 눈금**, 범위는 0.001~5,000, 눈금은 0.001 / 0.01 / 0.1 / 1 / 10 / 100 / 1,000이다.
- y축은 창 ROC-AUC이고 범위는 0.775~0.90이다.
- 계열 3개:
  - PatchTST 깊이 축(L1, L2, L3, L6): 남색 원. 점 위에 L1/L2/L3/L6 라벨을 달고, 연한 회청 오차막대(=SD 열)를 붙인다.
  - d64L2: 초록 마름모, 크게. 같은 초록으로 오차막대(=SD)를 붙인다.
  - 도메인 특징 4개 + 회귀: 빨간 사각형(x=0.001, y=0.7974). 오차막대는 없다.
- 참조 L6 AUC 0.8629를 중심으로 ±0.02(0.8429~0.8829)를 연한 남색 가로 띠로 칠하고, 띠 위 왼쪽에 "동등성 마진 ±0.02"라고 적는다.
- d64L2를 가리키는 초록 곡선 화살표와 굵은 글씨 "연산량 91배 절감 / AUC -0.012"를 넣는다. 91배는 3498.78 ÷ 38.34, -0.012는 0.8511 − 0.8629다.
- 오른쪽 위 구석에 작은 회색 글씨로 "오차막대 = 시드 3개 SD"를 적는다.
- 범례는 오른쪽 아래에 둔다.
- 제목: (b) 계산을 늘려도 나아지지 않는다

엑셀 팁: "분산형" 차트를 쓰고, 가로 축 서식에서 "로그 눈금 간격"을 체크한다. 오차막대는 "오차 막대 → 기타 옵션 → 사용자 지정 → 값 지정"에서 SD 열을 +와 − 모두에 넣는다. 가로 띠는 도형(사각형)을 반투명으로 얹는 것이 가장 쉽다.

## 그림 3. 특징 수 대 성능 (단일 패널): `fig3_특징수_AUC.csv`
- x축은 k = 1~8이고, 라벨은 "선택한 특징 수 k (후보 54개)"다.
- y축은 창 ROC-AUC이고 범위는 0.70~0.885다.
- 선 2개:
  - fixed: 회청 파선, 사각 마커. 범례는 "fixed — 전체 데이터에서 순위 (낙관 편향)"이다.
  - greedy: 초록 실선, 원 마커, 굵게. 범례는 "greedy — fold 안 검증집합에서만 선택"이다.
  - `greedy 피험자 AUC` 열은 그림에는 없고 본문 인용용이다.
- 가로선 2개:
  - y = 0.8629: 남색 파선. 오른쪽 끝에 "참조 모델 p16d128L6 .8629"라고 적는다.
  - y = 0.8004: greedy k≥4 구간의 최댓값이며 초록 점선이다.
- k≈1.3 위치에 0.8004와 0.8629 사이를 잇는 빨간 양방향 화살표를 긋고, 옆에 "남은 6.25%p는 소수 특징으로 / 환원되지 않는다"라고 적는다.
- k=4 점을 가리키는 초록 화살표와 굵은 글씨 "k = 4에서 포화 / .7974 = 참조의 93%"를 넣는다. 93%는 0.7974 ÷ 0.8629다.
- 범례는 오른쪽 아래에 둔다.
- 제목: 판별 정보는 소수 축에 있으나, 전부는 아니다

## 그림 4. Occlusion 근거 구간 (좌우 2패널, 왼쪽이 약 1.6배 넓음)

### (a) 묶은 막대 + 시드별 점: `fig4a_채널별_dz.csv`
- x축에는 6채널을 둔다: 마이크, 그립력, 축압력, 기울기X, 기울기Y, 기울기Z.
- 채널마다 막대 2개를 둔다. 왼쪽은 환자(빨강 `#b03a2e`), 오른쪽은 정상(슬레이트 `#5d6d7e`)이다.
- 막대 높이는 `dz 평균(막대)`, 검은 오차막대는 `SD(오차막대)`다.
- 각 막대 위에 시드 3개 값 `dz(시드42/1/7)`를 작은 검은 점으로 찍는다.
- y=0에 검은 가로선을 긋는다.
- y축은 "근거 구간의 4–6Hz 집중도 (Cohen d_z)"이고 범위는 약 −0.85~1.45, 눈금은 −0.5 / 0 / 0.5 / 1.0이다.
- 축압력·환자 막대를 가리키는 빨간 화살표와 "Holm p < .01 / 세 시드 일치"를 넣는다. Holm p 열에서 세 시드 모두 0.01 미만인 것은 이 칸 하나뿐이다.
- 범례는 왼쪽 아래에 환자 (n=26), 정상 (n=35)로 둔다.
- 제목: (a) 축압력 채널에서만, 환자에서만 유의하다

### (b) 막대 + 시드별 점: `fig4b_과제별_dz.csv`
- 대상은 환자군의 축압력 채널 하나이며, 과제별로 따로 계산한 값이다.
- x축은 나선 / 구불선 / 원 / 손뒤집기다.
- 막대 색은 효과가 클수록 진하게 한다: `#7b241c`, `#a04000`, `#ca6f1e`, 손뒤집기만 회색 `#7f8c8d`.
- 막대 높이는 평균, 검은 오차막대는 SD이고, 시드 3개 값을 점으로 찍는다.
- y축은 "환자 · 축압력 Cohen d_z"이고 범위는 −0.4~1.3이다.
- 제목: (b) 그림을 그릴수록 강하고, 손뒤집기에선 사라진다

엑셀 팁: 시드별 점은 막대 차트에 "분산형" 계열을 추가해서 겹친다. 점의 x 위치는 막대 중심(묶은 막대면 채널 번호 ± 0.2 정도)에 맞춘다. d_z의 z는 서식에서 아래 첨자로 만든다.
